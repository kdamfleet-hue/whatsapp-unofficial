# WhatsApp Unofficial Clients

هذا المستودع يحتوي على بديلين غير رسميين للتعامل مع WhatsApp:
1. **Baileys**: مكتبة تعتمد على WebSockets.
2. **WPPConnect**: مكتبة تعتمد على Puppeteer للتحكم بمتصفح.

**تنبيه هام:** 
هذه المشاريع هي نسخ غير رسمية ولن يتم تهيئتها لربط أي رقم WhatsApp حقيقي. يتم استخدامها لأغراض التجربة والتطوير فقط.
